PÁGINA DE CITA - 3 OPCIONES 💗

Archivos:
- index.html
- styles.css
- script.js

Personalización:
Abre script.js y busca const data.
Puedes cambiar:
1. prankPlace = lugar de broma.
2. prankText = texto de broma.
3. realMessage = texto antes de las tres opciones.
4. options = las 3 opciones reales.

Cada opción tiene:
- icon
- label
- title
- description

Ejemplo:
{
  icon: "🎳",
  label: "OPCIÓN 1",
  title: "Boliche",
  description: "Una partida juntos y después algo para comer."
}

Flujo:
Pregunta -> respuesta sí -> lugar de broma -> revelar -> tres opciones reales -> elegir una.

No necesita servidor ni base de datos.
